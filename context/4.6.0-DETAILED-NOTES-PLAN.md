# 4.6.0 Detailed Notes Plan

## Goal

Add a fourth Notes display mode, Detailed, before Expanded. Detailed is the
default all-locations view and shows complete location/note information without
truncation. Make the same Detailed / Expanded / Condensed / Text Only controls
available inside an individual location's Visit Notes section.

## Behavior

- Persist `notesViewMode: "detailed"` alongside the existing `expanded`,
  `compact`, and `text` values.
- New/default app state starts in Detailed. Existing saved view choices remain
  unchanged after normalization.
- Detailed all-locations view renders one location card with:
  - location type/name and applied levels;
  - note count and available date span;
  - every matching note as a complete nested card.
- Detailed note cards show all populated note fields: date, level, priority,
  tags/icons, Waypoint source, where, city, coordinates, what, who, and full
  details text.
- Individual-location Visit Notes gets the same four-mode segmented control.
  It uses the current persisted Notes view mode and ignores global list filters,
  matching existing selected-location behavior.
- Expanded, Condensed, and Text Only retain their current information density.

## Implementation

1. Open `4.6.0.1` and add a release-note entry.
2. Add the Detailed control with `__RECTANGLE_EXPAND_DIAGONAL`.
3. Extend defaulting, normalization, save/restore, summaries, and button state.
4. Add reusable full-note and detailed-location renderers.
5. Render the four-mode control inside selected-location Visit Notes.
6. Add responsive, theme-aware Detailed card styles with no ellipsis/clamping.
7. Update Help/FAQ, handoff, and shortcut documentation.
