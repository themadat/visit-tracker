Import and Export

Data is saved in this local browser only.
Use the Import/Export features to move your data between Devices and Browsers.
- JSON (.json): full data backup; re-importable to other Devices/Browsers.
- Markdown (.md): structured text; use for pretty rendering or HTML based applications.
- Rich Text (.rtf): formatted text; for word processors with basic formatting.
- Plain Text (.txt): simple text; used anywhere, useful for basic notes.

JSON restores your full map. Text exports are for sharing, notes, or printing.

Documentation

  1. Tap a state to mark it. In cycle mode, repeated taps rotate through your active levels and back to unvisited.
  2. Switch to select mode in Settings if you prefer adding a level and a quick dated note in one step.
  3. Select a state to open details. With Notes active, details appear beside the legend; otherwise they slide in from the side.
  4. Use the Legend to edit level names, definitions, and colors. Add optional built-in levels or your own custom levels.
  5. Use Import and Export in Settings to back up data or move it to another device.

Default levels: Visited and Not Interested. Not Interested is the opt-out level and is excluded from total completion.

Export formats: JSON (.json) is a full backup, re-importable into this app. Markdown (.md) renders in Obsidian, Notion, or any Markdown viewer. Rich Text (.rtf) opens in Word or Pages. Simple Text (.txt) pastes anywhere.

FAQ

Where is my data saved?
In your browser localStorage on this device only. Nothing leaves your machine.

Can someone else use the same app link?
Yes. Each browser keeps its own separate local copy of the data.

Does it work offline?
Yes. Once the file is open, no network connection is needed — there's no backend or external service.

Can I move data to another device?
Export a JSON backup in Settings, then import it in the app on the other device.

Can I undo a reset?
No. Export a JSON backup first if you want a safety net.

What's the difference between cycle and select mode?
Cycle taps rotate through your active levels automatically. Select mode opens a picker so you can choose a level and add a note in one step.

Can I have more than five levels?
No. Five is the cap — enough for any reasonable visit taxonomy without turning the legend into a spreadsheet.
